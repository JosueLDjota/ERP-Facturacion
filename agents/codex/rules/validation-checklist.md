# Checklist Obligatorio de Validación

Toda tarea relevante debe cerrarse respondiendo este checklist de salida.

## Resumen del cambio

- [ ] Qué problema resolvió.
- [ ] Qué comportamiento esperado queda cubierto.

## Superficie intervenida

- [ ] Qué archivos tocó.
- [ ] Qué archivos deliberadamente no tocó para minimizar riesgo.

## Decisión de diseño

- [ ] Por qué eligió esa capa, módulo o punto de inserción.
- [ ] Qué alternativa más invasiva descartó y por qué.

## Validación

- [ ] Qué validó funcional o técnicamente.
- [ ] Qué pruebas ejecutó.
- [ ] Qué pruebas deberían correrse adicionalmente si no se ejecutaron.

## Riesgo residual

- [ ] Qué riesgos pendientes, supuestos o limitaciones quedan abiertos.
- [ ] Si el cambio es reversible y cómo se aislaría si generara regresión.
